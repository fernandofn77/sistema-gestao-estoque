#  Sistema de Gestão de Estoque

Sistema de gestão de estoque desenvolvido com **HTML, CSS e JavaScript**, com o objetivo de facilitar o controle de produtos e o acompanhamento das movimentações de estoque.

##  Objetivo

Desenvolver uma aplicação web para praticar conceitos de desenvolvimento front-end, organização de código e criação de funcionalidades úteis para o gerenciamento de estoque.

##  Funcionalidades

-  Cadastro e gerenciamento de produtos
-  Controle de entradas de estoque
-  Controle de saídas de estoque
-  Acompanhamento da quantidade de produtos
-  Histórico de movimentações
-  Monitoramento de estoque mínimo
-  Organização de produtos por categorias

> As funcionalidades serão documentadas e atualizadas conforme a evolução do projeto.

##  Tecnologias utilizadas

- **HTML5** — estrutura da aplicação
- **CSS3** — estilização e layout
- **JavaScript** — lógica e interatividade

##  Como executar o projeto

1. Faça o download ou clone este repositório.
2. Extraia os arquivos, caso tenha baixado o ZIP.
3. Abra a pasta do projeto no Visual Studio Code.
4. Abra o arquivo `index.html` no navegador.

Você também pode utilizar a extensão **Live Server** do Visual Studio Code para executar a aplicação durante o desenvolvimento.
